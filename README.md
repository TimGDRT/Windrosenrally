# Windrosen-Rallye

Kleine Webseite für die QR-Rallye im Geografieunterricht (C4.1).

- `station1.html` … `station5.html`: eine Seite pro Station (Buchstabe + Hinweis)
- `index.html`: Startseite ohne Hinweise
- `qr-codes.html`: Lehrerseite, erzeugt die QR-Codes für die eigene Adresse und lässt sich drucken
